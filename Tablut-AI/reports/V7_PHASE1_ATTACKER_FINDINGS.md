### 1.1 一处刻意保留的偏差（已在测试中显式声明）

国王在**城堡格上被吃**时，官方裁判把该格写成 `.`；我们的 `apply_move` 写 `X`。
原因：`parse_board` 要求城堡格只能是 `K` 或 `X`，写成 `.` 会让任何对终局棋盘的再次读取失败。
终局已定，这一格没有规则意义，因此保留不变量并让测试显式容许这一个格子差异（`assert_same_transition` 中有注释）。

## 3. P0-2 的发现（54 局同代对局）

### 3.1 攻方不是输在"漏看一步杀"

54 局里攻方一步杀可用而没走的决策：**0 次**（70 局混合语料里同样为 0）。
结合 `reports/phase3` 的战术基线（19 次一步围捕全部命中），可以确认：**败局来自战略/位置层面，不是战术漏杀**。
这支持"攻方需要的是空间控制与围捕结构，而不是再多几层战术搜索"的判断。

### 3.2 静态封锁指标不能单调区分胜负

以"首次出现立即逃生格"分桶（攻方视角）：

| 首次立即逃生 | 攻方胜 | 和 | 攻方负       |
| ------------ | ------ | -- | ------------ |
| ply 0–10    | 5      | 5  | 8            |
| ply 11–16   | 1      | 4  | **13** |
| ply 17–22   | 0      | 2  | 3            |
| ply 23–30   | 0      | 2  | 2            |
| ply 31+      | 2      | 0  | 3            |
| 从未出现     | 2      | 2  | 0            |

中位数：胜 8 步、负 16 步、和 14 步 —— **胜局的首次逃生反而更早**，因为它们大多是"快速捕获"，而不是"长期封锁"。
结论：**"国王何时出现逃生格"不是有效封锁的判据**，用单一几何量替代真实攻守对抗正是方案 §4.1 警告的错误。

### 3.3 真正有区分度的是"封锁能否维持并转化为夹击"

按结局分组的采样子集均值（步长 4 采样，攻方视角）：

| 指标                               | 攻方胜 (n=10)   | 和 (n=15) | 攻方负 (n=29) |
| ---------------------------------- | --------------- | --------- | ------------- |
| 完全封锁占比（两回合内够不到边缘） | **0.387** | 0.318     | 0.293         |
| 最后一次完全封锁的平均步数         | **44.5**  | 4.8       | 12.3          |
| 国王平均合法走法数                 | 2.99            | 3.88      | 3.79          |
| 国王相邻攻击者的历史最大值         | **1.70**  | 0.60      | 0.97          |

三条可读的差异：**胜局的封锁占比更高、封锁维持得更久、并且真的把攻击者贴到国王身上形成了夹击结构**；
和局是"封不住也没输"；负局介于两者之间（封不住、也贴不上）。

### 3.4 按对局来源分层

| 对局  | 局数 | 攻方胜/和/负 | 完全封锁占比    | 国王平均走法   |
| ----- | ---- | ------------ | --------------- | -------------- |
| v3_v4 | 20   | 4 / 5 / 11   | 0.280           | 3.88           |
| v4_v5 | 20   | 3 / 7 / 10   | 0.250           | 3.93           |
| v5_v6 | 14   | 3 / 3 / 8    | **0.467** | **2.98** |

新一代候选的对手同样变强，因此**不能**据此断言"越新的引擎攻方越强"；但封锁占比与国王机动性这两项在同一语料内方向一致。

## 4. P0-3：有效/无效封锁的可操作判据（供下一步实验使用）

给出**可计算、可复现**的定义，而不是叙述性描述。位置 p 对攻方而言是"有效封锁"，当且仅当同时满足：

1. `immediate_escape(p) == 0` —— 国王没有任何一步到边缘的走法；
2. `escape_reach_2(p) == 0` —— 国王两步之内也够不到任何边缘格；
3. 存在夹击结构：`king_adjacent_attackers(p) >= 2` 且其中至少一对位于国王的**相对方向**
   （这是裁判认可的捕获几何，不是"外围摆子"）；
4. 稳定性：贴身的攻击者中，**没有一个**处在"守方下一手可吃"的状态（支撑位为空或只有守方棋子）。

否则为"无效封锁"，并按失败原因细分为四类：`缺口型`（1 或 2 不满足）、`无结构型`（3 不满足）、
`不稳型`（4 不满足）、`多因型`。

### 4.1 判据在 54 局上的分布（每 4 步采样一次攻方决策，共 471 个样本）

| 攻方结局            | 样本 | 有效封锁       | 无结构（远处控制住） | 缺口型          | 不稳型 |
| ------------------- | ---- | -------------- | -------------------- | --------------- | ------ |
| **胜 (n=10)** | 114  | **9.6%** | **50.9%**      | 37.7%           | 1.8%   |
| 和 (n=15)           | 101  | **0.0%** | 27.7%                | **72.3%** | 0.0%   |
| 负 (n=29)           | 256  | **0.4%** | 30.5%                | **69.1%** | 0.0%   |

三条结论：

1. **"有效封锁"几乎只出现在胜局**（9.6% vs 负局 0.4%、和局 0%），是最强的单点信号；
2. 但胜局里最常见的状态是**"无结构"（50.9%）**——国王没有逃生格、两回合内也够不到边缘，但身边不足两名攻击者。
   这正是方案里说的"外围控制"：**不贴身也能封住**，而且它是胜局最常见的形态；
3. 负局与和局都以 **"缺口型"** 为主（约 70%），即封锁本身已经漏了，而不是"封锁住了却打不开"。

也就是说，攻方的问题不是"围得太近导致外围失控"（见 §5 的 H1 检验），而是**根本没有形成稳定封锁**：
负局里 70% 的决策时刻已经存在逃生缺口。

## 5. P0-4：外围控制与突破预防（两条假设都已检验，一条被否证）

### H1（"贴身导致外围失控"）：**未获支持**

| 攻方走法                    | 事件数 | 6 步内出现立即逃生的比例 |
| --------------------------- | ------ | ------------------------ |
| 从距王 ≥3 缩到 ≤2（贴身） | 137    | **39.4%**          |
| 其他攻方走法                | 260    | **56.5%**          |

贴身的走法**反而**比一般走法更少导致随后出现逃生格。注意这是相关性而非因果：引擎通常在"贴身安全"时才贴身。
但至少可以否定"把棋子调近国王是主要败因"这一条朴素读法。

### H2（"结构优先于数量"）：**捕获率随相邻攻击者数量强烈上升，但被终局邻近性混杂**

| 相邻攻击者 | 相对方向对数 | 样本 | 该局最终捕获国王的比例 |
| ---------- | ------------ | ---- | ---------------------- |
| 0          | 0            | 283  | 14.5%                  |
| 1          | 0            | 162  | 31.5%                  |
| 2          | 0            | 11   | **81.8%**        |
| 2          | 1            | 7    | 71.4%                  |
| 3          | 1            | 8    | **100%**         |

相邻数量与最终捕获强相关；但"相邻=2 且无相对夹击"也有 81.8% 的捕获率，说明**决定因素是"贴到国王身边"**，
而不是"是否恰好摆在相对方向"。样本量（11/7/8）很小，且相邻往往出现在终局附近，存在前后选择偏差，不能当因果结论。

### 5.1 由此得到的可执行判断

1. 攻方的核心缺口是**封锁的形成与维持**，不是"贴太近"或"漏一步杀"；
2. "远处就能封住"（无结构型有效封锁）是胜局最常见的形态，值得作为新特征的第一候选：
   **在国王没有逃生格、两回合够不到边缘的前提下，攻击者离王越远、外围控制点越多，评分越高**；
3. 下一步的攻方变体应当优先实现"外围控制"（A1），而不是"更快贴身"（A2 若按"增加相邻攻击者"实现，会与 H1/H2 的证据相冲突，需要改成"形成合法夹击结构"而非"增加相邻数量"）。

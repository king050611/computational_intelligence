## 指标和实验模型

- 空间评分依据攻击者挡住的射线，以及移走所有攻击者之后恢复的两步几何逃生空间。初始盘的四个守方阻挡记为自身阻挡，攻方空间评分从 0.85 降至 0。
- 战术逃生指标统计最多两次守方走棋内可以确保国王到达边缘的第一步。分析包含守卫让路、真实捕获、攻方全部合法应手及重复和棋。
- 普通区域分别评估横向和纵向夹击。可达性排除为了占据缺口而撤走同轴支撑的走法。城堡区域按课程规则评估。
- 稳定性诊断覆盖外围关键棋子，检查守方下一手能否捕获并打开逃生空间。这个指标的观察窗口是一手，包含可捕获的棋子，未衡量更长序列中的被迫撤离。
- A0 是原冠军。A1 加入空间评分，A2 加入围捕结构评分，A3 同时使用两者。初始实验权重分别为 120、120 和各 60。叶节点使用低开销几何及结构评分，完整应手和外围稳定性验证用于离线分析。

## 运行固定攻方实验

从 Tablut-AI 目录执行。首轮四组各 16 局，冻结冠军守方及两个专项守方。所有模型采用相同对手、开局、深度 4、每方 60 秒。次轮只有在首轮给出正向证据后才运行，基线和入选模型各 40 局，使用新的种子。把示例的 A1 换为首轮实际入选模型。

```powershell
python -m scripts.run_attacker_strategies --stage screen
python -m scripts.run_attacker_strategies --stage confirm --finalist A1
```

中断后在原命令加 `--resume`。结果目录包含分局 JSON、HTML 回放及按对手汇总的胜平负和最大累计耗时。只有独立结果支持更高胜率且无超时或非法走法，才有依据恢复攻方遗传训练。

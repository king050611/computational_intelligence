## 已验证

- 双权重 Schema 3 每次搜索只按根节点执棋方选一组权重。搜索子节点沿用该权重。旧 Schema 1 和 2 仍可读取。
- 攻守种群分别运行，使用冻结对手池、同场积分底线和可恢复的独立目录。单元测试覆盖角色调度、积分排序、阶段数量和续跑。全量回归 153 项通过。另用课程裁判运行一局一步围捕的冒烟测试，实测 JSON 棋谱可以直接复用，续跑未重打该局。
- 249 个局面在观察模型结果前按来源对局分组。开发集 175，回归集 37，留出集 37。基线仅使用开发集和回归集。
- 六个冻结模型分别运行 212 个局面，目标深度 4，节点上限 500。共 1272 次评估，均返回合法动作。每个模型均匹配 19/19 的一步围捕和 30/30 的一步逃生答案。
- V4 冠军在安全应对上匹配 15/16，回归集的两步围捕匹配 5/5。Blockade 匹配 30/30 的封锁样本；Escape 匹配 28/30 的创造逃生通道样本。比例以本轮可见样本为分母，策略标签按参考走法解释。

原始诊断在 [开发集结果](tactics/development_baseline.json) 和 [回归集结果](tactics/regression_baseline.json)。搜索耗时是在 Phase 3 后台运行时记录的观察值。基线的走法表现需要通过正式对局验证。
